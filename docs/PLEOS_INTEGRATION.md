# Pleos Integration Boundary

No Pleos SDK calls are included in this repository yet. The available SDKs, project access state, exact method signatures, capabilities, and Android permissions must be checked against the official Pleos documentation and the target project's Playground access before implementation.

Future Android data providers should map SDK output into the shared vehicle, location, and transcript contract. Release listeners and SDK resources with the Android lifecycle. Do not substitute fabricated live values when an SDK capability is unavailable. The Web Simulator remains the supported provider while those prerequisites are unavailable.
